# 用户使用手册

## 快速开始

### 1. 创建房间

1. 打开应用首页
2. 输入你的昵称
3. 点击「创建房间」按钮
4. 系统自动生成 6 位房间号
5. 点击「复制邀请链接」按钮
6. 将链接发送给你的朋友

### 2. 加入房间

**方法一：通过邀请链接**
1. 点击朋友发送的邀请链接
2. 页面自动填入房间号
3. 输入你的昵称
4. 点击「加入房间」

**方法二：手动输入**
1. 打开应用首页
2. 在「加入房间」区域输入房间号
3. 输入你的昵称
4. 点击「加入房间」

### 3. 等待管理员批准

- 创建房间者自动成为管理员
- 其他用户加入时需要管理员批准
- 管理员界面会弹出审批提示

## 功能说明

### 连麦（视频语音）

- 默认关闭摄像头和麦克风
- 点击底部麦克风按钮开启/关闭麦克风
- 点击底部摄像头按钮开启/关闭摄像头
- 连麦视频以画中画形式显示在右下角

### 屏幕共享（仅 PC 端）

#### 发起共享（普通用户）

1. 点击底部「共享屏幕」按钮
2. 选择画质（2K 60fps / 1080p 60fps / 1080p 30fps / 720p 60fps）
3. 点击「申请共享」
4. 等待管理员批准
5. 管理员批准后，选择要共享的屏幕/窗口/标签页
6. 共享开始

#### 管理员操作

- **批准/拒绝共享申请**：在「设置」标签页查看共享请求，点击「批准」或「拒绝」
- **撤销共享**：如果当前有人共享，点击底部「撤销共享」按钮
- **切换画质**：共享开始后，在「设置」标签页选择画质档位

#### 停止共享

- 点击底部「停止共享」按钮
- 或点击浏览器工具栏的「停止共享」按钮

### 管理员功能

- **踢人**：在成员列表中点击用户右侧的「踢出」按钮
- **批准/拒绝加入**：新用户加入时弹出审批提示
- **批准/拒绝共享**：在「设置」标签页管理共享请求
- **撤销共享**：强制停止当前共享

## 桌面快捷方式（Windows）

### Chrome 浏览器

1. 打开 Chrome 浏览器
2. 访问 `https://你的域名/?room=房间号`
3. 点击右上角 ⋮（三个点）图标
4. 选择「更多工具」→「创建快捷方式...」
5. 在弹出的对话框中：
   - 输入快捷方式名称（如「观赛房间 ABC123」）
   - ✅ 勾选「在窗口中打开」（推荐，体验更好）
6. 点击「创建」
7. 桌面上会出现一个快捷方式图标，双击即可直接打开

### Edge 浏览器

1. 打开 Edge 浏览器
2. 访问 `https://你的域名/?room=房间号`
3. 点击右上角 ⋯（三个点）图标
4. 选择「应用」→「将此站点作为应用安装」
5. 在弹出的对话框中：
   - 输入应用名称（如「观赛房间 ABC123」）
6. 点击「安装」
7. 桌面和开始菜单中会出现快捷方式，双击即可直接打开

### 快捷方式效果

创建快捷方式后：
- 双击即可直接打开对应房间
- 窗口无地址栏，体验类似原生应用
- 可以固定到任务栏方便下次使用

## 画质说明

| 档位 | 分辨率 | 帧率 | 目标码率 | 适用场景 |
|------|--------|------|----------|----------|
| 2K 60fps | 2560×1440 | 60fps | 8Mbps | 高速运动画面（比赛、游戏） |
| 1080p 60fps | 1920×1080 | 60fps | 4Mbps | 一般视频内容 |
| 1080p 30fps | 1920×1080 | 30fps | 2.5Mbps | 静态内容、PPT |
| 720p 60fps | 1280×720 | 60fps | 2Mbps | 网络状况不佳时 |

**提示**：
- 默认 2K 60fps，需要较好的网络环境
- 如果共享卡顿，可以尝试降低画质
- 系统会根据网络状况自动降级画质

## 常见问题

### 房间号无效？

- 房间号为 6 位字母数字（大写）
- 注意区分相似字符：0（数字零）和 O（字母欧）、1（数字一）和 I（字母爱）
- 如果仍无法加入，请确认房间是否已解散

### 看不到共享画面？

- 确认共享者已选择屏幕并开始共享
- 检查浏览器是否授予了屏幕录制权限
- 尝试刷新页面

### 听不到声音？

- 确认共享者已开启音频共享（浏览器提示时勾选「共享音频」）
- 检查系统音量是否开启
- 确认浏览器标签页未被静音

### 连麦没有画面？

- 确认已点击摄像头按钮开启摄像头
- 检查浏览器是否授予了摄像头权限
- 确认没有其他应用占用摄像头

### 管理员离开后房间解散？

- 这是正常设计：管理员离开后房间自动解散
- 所有成员会收到提示
