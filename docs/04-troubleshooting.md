# 排障手册

## 连接问题

### 无法连接 MQTT Broker

**症状**：页面显示「连接中...」或「已断开」

**可能原因**：
1. 网络问题
2. 公共 EMQX Broker 暂时不可用
3. 防火墙阻止了 WebSocket 连接

**解决方案**：
1. 检查网络连接是否正常
2. 尝试刷新页面
3. 检查公司/学校防火墙是否阻止了 `wss://broker.emqx.io:8084`
4. 等待几分钟后重试

### 加入房间失败

**症状**：输入房间号后提示「加入房间失败」

**可能原因**：
1. 房间号错误
2. 房间已解散
3. 连接 MQTT 失败

**解决方案**：
1. 确认房间号正确（6位大写字母数字）
2. 联系创建房间者确认房间是否还在
3. 检查网络连接

### 房间已满

**症状**：提示「房间已满」

**原因**：房间已达到最大人数限制（6人）

**解决方案**：
1. 等待有人离开后再加入
2. 创建新房间

## 媒体问题

### 无法获取摄像头/麦克风

**症状**：点击摄像头/麦克风按钮无反应，或提示「无法访问」

**可能原因**：
1. 浏览器未授予权限
2. 设备被其他应用占用
3. 系统隐私设置阻止

**解决方案**：

**Chrome/Edge**：
1. 点击地址栏左侧的锁形图标
2. 找到「摄像头」和「麦克风」权限
3. 设置为「允许」
4. 刷新页面

**Windows 系统设置**：
1. 打开「设置」→「隐私」→「相机」
2. 确保「允许应用访问你的相机」已开启
3. 在列表中找到浏览器并开启权限
4. 同样检查「麦克风」权限

**macOS 系统设置**：
1. 打开「系统偏好设置」→「安全性与隐私」→「摄像头」
2. 在列表中找到浏览器并勾选
3. 同样检查「麦克风」权限

### 看不到共享画面

**症状**：主画面区域仍显示「等待屏幕共享」

**可能原因**：
1. 共享者尚未选择屏幕
2. 共享者选择了错误的窗口
3. 网络问题导致媒体流未传输

**解决方案**：
1. 确认共享者已点击浏览器弹出的「共享」按钮
2. 确认共享者选择了正确的屏幕/窗口/标签页
3. 检查网络连接
4. 尝试让共享者停止共享后重新开始

### 共享画面卡顿

**症状**：共享画面不流畅、延迟高

**可能原因**：
1. 网络带宽不足
2. 共享者 CPU 占用过高
3. 画质设置过高

**解决方案**：
1. 降低共享画质（如从 2K 降到 1080p 或 720p）
2. 关闭其他占用网络的应用
3. 关闭不必要的浏览器标签页
4. 系统会自动降级画质，等待几秒观察

### 连麦有回声

**症状**：听到自己的声音回响

**可能原因**：
1. 扬声器声音被麦克风拾取
2. 多人同时开启麦克风

**解决方案**：
1. 使用耳机（最有效）
2. 不说话时关闭麦克风
3. 降低扬声器音量

### 连麦声音小

**症状**：对方声音听不清

**解决方案**：
1. 检查对方麦克风是否开启
2. 调大系统音量
3. 检查浏览器标签页是否被静音（右键标签页查看）
4. 确认没有其他应用占用麦克风

## 浏览器兼容性

### 支持的浏览器

| 浏览器 | 最低版本 | 支持情况 |
|--------|----------|----------|
| Chrome | 74+ | ✅ 完全支持 |
| Edge | 79+ | ✅ 完全支持 |
| Firefox | 66+ | ✅ 基本支持（VP9 可能不支持） |
| Safari | 14+ | ⚠️ 部分支持（iOS 屏幕共享不支持） |
| Opera | 62+ | ✅ 基本支持 |

### 推荐浏览器

**强烈推荐使用 Chrome 或 Edge 浏览器**：
- 支持 VP9 编码（更好的画质）
- 屏幕共享功能最稳定
- WebRTC 性能最佳

### 不支持的功能

- **Safari（iOS）**：不支持屏幕共享（系统限制）
- **微信内置浏览器**：WebRTC 支持有限，不推荐使用
- **IE 浏览器**：完全不支持

## 权限问题

### 屏幕录制权限

**症状**：点击共享屏幕后浏览器不弹出选择框

**解决方案**：

**Windows**：
1. 打开「设置」→「隐私」→「屏幕录制」
2. 确保浏览器在允许列表中

**macOS**：
1. 打开「系统偏好设置」→「安全性与隐私」→「屏幕录制」
2. 在列表中找到浏览器并勾选
3. 重启浏览器

### 摄像头/麦克风权限被记住为「阻止」

**症状**：浏览器不弹出权限请求

**解决方案**：
1. 点击地址栏左侧的锁形图标或信息图标
2. 找到「权限」或「网站设置」
3. 将摄像头和麦克风权限重置为「询问」或「允许」
4. 刷新页面

## 高级问题

### MQTT 连接频繁断开

**症状**：连接状态频繁在「已连接」和「连接中」之间切换

**可能原因**：
1. 网络不稳定
2. 公共 Broker 负载过高
3. NAT 超时

**解决方案**：
1. 切换到更稳定的网络（如从 WiFi 换到有线）
2. 等待几分钟后重试
3. 刷新页面重新连接

### WebRTC 连接建立失败

**症状**：连麦看不到对方画面

**可能原因**：
1. NAT 类型限制（对称 NAT）
2. 防火墙阻止 UDP 流量
3. STUN 服务器不可用

**解决方案**：
1. 尝试切换网络（如从公司网络换到家庭网络）
2. 检查防火墙是否允许 UDP 流量
3. 极少数情况下，对称 NAT 可能导致连接失败，此时需要 TURN 服务器（本项目未配置）

### 页面崩溃

**症状**：页面无响应或浏览器提示「页面无响应」

**可能原因**：
1. 内存不足（打开了太多标签页）
2. 浏览器扩展冲突
3. 设备性能不足

**解决方案**：
1. 关闭不必要的标签页
2. 尝试无痕模式（禁用扩展）
3. 重启浏览器

## 联系与反馈

如果以上方法无法解决问题，请：

1. 尝试使用 Chrome 浏览器的最新版本
2. 检查浏览器控制台（F12 → Console）是否有错误信息
3. 联系创建房间者确认房间状态
